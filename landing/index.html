Java 反序列化漏洞靶场

从原理到实战，系统化学习 Java 反序列化漏洞的触发机制与利用链构造

关于靶场

本靶场包含 18 道渐进式题目，从最基础的 Runtime.exec() 命令执行， 到 Commons-Collections 各组件的拆解学习，再到完整的 CC1-CC7 利用链实战。 每道题都可在线上传序列化 payload，服务端反序列化后触发预设命令执行。

学习路径

  • 基础篇（class01-04）：理解 Java 反序列化基本原理，认识 readObject()、toString() 等触发点
  • 组件篇（class07-13）：逐一拆解 Commons-Collections 的 Transformer 组件，掌握每个类的调用逻辑
  • 利用链篇（class14-20）：组合组件构造完整的 CC1-CC7 利用链，理解 ysoserial 的攻击原理
  • 进阶实验：RMI 反序列化攻击场景

使用方法

使用 Java 生成序列化 payload（.ser 文件），通过 curl 上传到对应题目：

# 1. 生成 payload（在 poc/ 目录下）
cd poc/class07-invoker/ && bash gen.sh

# 2. 上传 .ser 文件到靶场
curl -F "uploadFile=@class07.ser" http://localhost:81/class07/upload

或将 .ser 文件通过网页端的 "选择文件" 按钮上传。

注意事项

  • 本环境仅用于授权安全学习，请勿用于非法用途
  • JDK 版本为 8u402，CC1/CC3 链因 AnnotationInvocationHandler 修复已失效
  • CC5 链需要 JDK 8 环境生成 payload（已提供 Docker 内生成脚本）
  • 使用 TemplatesImpl 的题目需启用 jdk.xml.enableTemplatesImplDeserialization=true

RMI 反序列化漏洞实验

本 Docker 服务包含多个 RMI 反序列化实验场景，分别对应不同的端口和服务类型。

实验一：JRMPListener 服务端

JRMPListener 1099 / 1100

利用 ysoserial 的 JRMPListener 启动恶意 RMI 服务端，等待客户端连接后返回 CC1 链 payload 执行命令。

# 启动恶意 RMI 服务端
java -jar ysoserial.jar JRMPListener 1099 CommonsCollections1 "calc"

实验二：注册表绑定漏洞

注册表绑定 3099

RMI 注册表直接绑定恶意序列化对象，当客户端查询时返回 payload 触发反序列化漏洞。

java -jar ysoserial.jar RMIRegistryExploit target-ip 3099 CommonsCollections6 "calc"

实验三：RMI 客户端攻击

客户端攻击 client/

客户端程序连接恶意 RMI 服务端（1099/1100），触发客户端反序列化漏洞。

java -jar rmi-client.jar
# 输入: rmi://target-ip:1099/Hello

实验四：正常 RMI 服务

正常 RMI 服务 2099 / 2100

标准 RMI 注册表服务，用于对比学习正常 RMI 通信流程。

rmiregistry 2099
⚠️ 重要提示：
• 请使用 JDK 1.8 版本进行实验
• 靶场源码位于 class05/class06 目录
• 客户端程序位于 client/rmi-client.jar
